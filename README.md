# 과제 관리 — 학교 공지 정리 웹페이지

작성자: 1316 조윤호

긴 학교 공지에서 과제명, 날짜, 제출 조건과 참고 링크를 추출하고 날짜순으로 확인하는 웹페이지입니다.

## 실행 방법

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. CSS, JavaScript, 예시 공지가 포함된 단일 HTML 파일이므로 설치 없이 사용할 수 있습니다. 외부 참고 링크를 제외한 공지 분석 기능은 인터넷 없이 실행됩니다.

1. 공지 전체를 붙여 넣거나 UTF-8 TXT 파일을 불러옵니다.
2. 연도가 생략된 날짜에 적용할 기준 연도를 확인합니다.
3. ‘과제 추출하기’를 누르고 결과를 확인합니다.
4. 항목을 선택해 추가하고, 목록에서 과제를 눌러 상세 내용을 봅니다.
5. 검색어를 복사하고 원래 공지에서 Ctrl+F로 검색합니다.
6. 실제 제출을 마친 후 ‘제출 완료로 표시’를 누릅니다.

## 파일 구성

- `index.html`: 제출·실행용 단일 파일
- `dist/index.html`: 분리된 웹페이지 구조
- `dist/style.css`: 화면 스타일과 반응형 레이아웃
- `dist/app.js`: 입력, 검색, 저장, 완료, 수정 등 화면 기능
- `dist/parser.js`: 과제 구분, 제목·날짜 추출, 검색어 생성, 기존 데이터 보정
- `dist/sample.txt`: 2026년 정보과학 공지의 축약 예시
- `tests/parser.test.cjs`: 추출 로직 검증 36개

분리된 소스는 프로젝트 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/dist/`에서 확인할 수 있습니다. Python은 파일을 제공하는 서버 역할만 합니다.

## 설계 및 구현

실생활 문제는 여러 과제와 마감이 긴 공지에 섞여 있어 필요한 정보를 찾기 어렵다는 것입니다. 입력은 공지 텍스트와 기준 연도이며, 출력은 마감일로 정렬된 과제 목록과 상세 조건입니다.

처리 순서: 서식 정리 → 과제 단위 분리 → 제목 추출 → 날짜 후보 분석 → 정렬 → 상세 정보 표시.

과제 객체를 배열로 관리하고 ID로 선택한 과제를 찾습니다. Map과 Set을 이용해 날짜 후보와 검색어의 중복을 제거합니다. 날짜를 시간값으로 변환하여 오름차순 정렬하며, 날짜가 없는 항목은 확인 필요로 분류합니다.

제목은 ‘과제:’, ‘탐구주제:’, ‘새 과제 게시:’ 등 명시된 제목을 우선합니다. 날짜는 본문에 명시된 제출기한이 우선이며, 없으면 제출·신청 제목의 날짜를 추정값으로 사용합니다. 검색어는 원문에 실제로 존재하는 문자열만 제안합니다. 브라우저 localStorage로 과제와 완료 상태를 저장합니다.

## 검증

Node.js 18 이상에서 프로젝트 폴더 기준으로 실행합니다.

```sh
node --test tests/parser.test.cjs
```

검증 항목: 제목에만 있는 날짜, 한글·점·슬래시 날짜, 본문 마감일 우선 적용, 다음 줄에 있는 기한, 오전·오후·자정, 윤년과 잘못된 날짜, 접수 기간, 같은 달의 축약 범위, 연장 날짜 누락, 마감일 충돌, 본문 뒤 제목, 중복 게시 알림, 연속 과제 분리, 기존 20개 예시, 검색어의 원문 일치, 완료 상태와 수동 수정값 보존. 36개 자동 테스트를 통과했습니다. 브라우저에서도 입력·저장·검색어 복사·원문 표시를 확인했습니다.

## 한계

HTML/CSS/JavaScript로 구현한 규칙 기반 프로그램이며 AI API는 사용하지 않습니다. 모든 자연어 표현을 완벽하게 이해하지 못하므로 추출 결과를 원문과 확인해야 합니다. 제목의 날짜는 행사일일 수도 있어 구분 표시합니다. 시간이 없으면 23:59:59로 정렬하며, 정확한 날짜가 없는 시험 일정과 이미지 속 글자는 분석하지 않습니다.

저장은 해당 기기와 브라우저에 한정됩니다. 사생활 모드나 브라우저 데이터 삭제, 파일 이동 등으로 저장 내용이 유지되지 않을 수 있습니다. 완료 표시는 실제 제출을 대신하지 않습니다. 다른 사람에게 코드 파일을 전달해도 브라우저에 저장한 개인 공지는 전달되지 않습니다.
