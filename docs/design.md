# 모아: 데스크톱 일정 목록

설치된 Anthropic frontend-design 스킬을 적용한다.
https://github.com/anthropics/skills/tree/main/skills/frontend-design

외부 참고: Linear의 작업 목록과 Raycast의 키보드 중심 탐색. 자산·문구를 복사하지 않고 목록 밀도와 제한된 강조 원칙을 참고한다.
https://linear.app/features
https://www.raycast.com/

색: 흰색 #FFFFFF, 옅은 면 #F7F8FA, 구분선 #E6E8ED, 본문 #25272E, 보조 #717682, 선택 강조 #5A64C7. 초록색은 사용하지 않는다. 임박 기한만 차분한 황갈색으로 표시한다.
글꼴: Segoe UI / 맑은 고딕. 제목 18px, 목록 12–13px, 보조 10–11px. 숫자를 크게 강조하지 않는다.

```text
모아   | 내 학습 공간 / 대시보드                          검색
탐색   | 대시보드                                        날짜
       | 마감 예정 7    기한 미정 6    완료 0    수업 17
수업   | 앞으로 7일:  6   7   8   9   10   11   12
       | 일정 / 필터                          작은 달력
       | □ 아이콘  제목                   날짜   원문
       |           수업 / 종류
```

왼쪽 정렬. 목록이 화면의 대부분을 차지하고 요약은 한 줄이다. 행을 클릭하면 그 행 바로 아래, 목록 너비로 원문 본문이 펼쳐진다. 본문을 별도로 클릭하게 만들거나 내부 스크롤로 자르지 않는다. 기한·첨부·개인 메모는 본문 뒤에 둔다. 근거·분석 설명과 오른쪽 상세 패널은 사용하지 않는다. 같은 행을 다시 누르거나 접기 버튼을 누르면 접힌다. 휴대전화는 이번 대상에서 제외하고 1280/1440/1920px 데스크톱을 검증한다.

검토: 기존 민트색 배경, 큰 과목 그림, 4개 요약 카드, 반복 안내 패널은 미니멀리즘 요청과 맞지 않아 제거했다. 날짜 확정 여부, 교내 신청과 외부 접수의 구분, 원문 링크는 유지한다.

한 게시물 안의 독립된 과제·수행평가 영역은 각각 행으로 표시한다. 제출 조건이나 단순 참고 목록은 과제로 분리하지 않는다. 본문·PDF에 있는 해당 과제의 날짜를 연결하며, 평가 기간은 시작일~종료일과 수업 시간 조건을 함께 표시한다. 수시·틈날 때마다 진행하는 활동에는 수시 진행을 표시한다. 다른 과제에서 가져온 연관 기한은 확인 필요로 구분하고, 본문과 API 마감 시각이 충돌하면 두 값을 본문 아래에 함께 남긴다. 화면을 열어도 추가 AI 호출은 없다.
