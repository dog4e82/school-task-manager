# 학교 계정의 수집·AI 정리

## 현재 흐름

1. 본인 Google 계정으로 연결하고 수업을 선택한다.
2. PDF 읽기를 허용한 경우 첨부 PDF 함께 읽기가 기본 선택된다. 스캔·권한 거부·지원하지 않는 형식은 별도 상태로 표시한다.
3. 사용자가 본문·추출 PDF 텍스트의 BAZE 전송에 동의하고 시작하면 수집 후 미분석 자료를 정리한다.
4. 본문이 저장되면 대시보드를 먼저 열고 PDF·AI는 백그라운드에서 이어간다. 진행 표시의 ‘정리된 결과 보기’에서 저장된 결과를 확인한다.
5. 같은 수업에서 같은 본문·첨부 입력을 읽을 수 있는 계정은 저장된 결과를 재사용한다. 다른 계정의 수업·개인 기록을 대신 표시하지 않는다.

새 분석은 `js.hs.kr` 학교 계정에서 사용할 수 있다. 다른 학교 도메인을 운영할 때는 실제 허용 대상에 맞춰 `SCHOOL_EMAIL_DOMAIN`을 변경한다. API 키는 운영 서버에서만 관리한다.

## 사용량 정책

운영자가 요청한 기준은 일일·회당 분석 건수 제한 없이, **새 호출 직전 합계 잔액이 2,000크레딧 미만이면 중단**하는 것이다. 잔액이 누락되거나 확인되지 않아도 새 생성을 시작하지 않는다. 진행 중인 호출은 완료될 수 있어 잔액이 항상 2,000 이상으로 보존된다고 보장하지 않는다. 동시 사용·반영 지연도 고려해야 한다. 잔액이 회복된 뒤 사용자가 다시 실행하면 성공 결과를 재사용하고 남은 항목을 처리한다.

모델은 `gpt-6.1-sol`을 유지한다. 학교 사용자가 별도 모델을 지정하거나 API 키를 입력하지 않는다. 실패·시간 초과·잘린 응답은 자동 재생성하지 않는다. Google 승인 한도, 학교 관리자의 외부 앱 정책, API 자체의 요청 제한은 이 서비스의 일일 한도와 별개다.

## 한 게시물의 여러 행동

AI 응답의 여러 지시와 본문·PDF 구간을 독립 항목으로 표시한다. 큰 입력은 60,000자 이내 구간으로 나눠 분석하며, 각 구간을 캐시하고 부모 게시물의 결과로 합친다. 일부 구간만 끝났다면 전체 성공으로 표시하지 않는다. PDF의 파일·페이지 출처와 원문 링크를 보존한다.

과제 여부의 확인 상태와 기한 확인 상태는 별도로 보관한다. 제출 의무가 불명확해도 Classroom에 등록된 기한은 표시할 수 있고, 명시된 과제라도 기한은 미정일 수 있다. 지난 기한은 기본 목록에서 숨기며 원문이나 분석을 삭제하지 않는다.

이후 동기화에서 관측한 등록 기한·본문 변경은 계정별 최근 100건까지 남긴다. 본문 변경을 발견했다는 이유로 새로운 날짜를 임의로 확정하지 않는다. 개인 메모·구두 안내의 날짜는 공식 등록 기한과 구분한다.

## 남은 검증

Google 브랜딩 게시와 데이터 접근 검증은 별개다. 제한된 Drive PDF 읽기 권한은 실제 권한 사용 설명과 동의·기능 시연 영상이 필요하며, 서버 처리에 대한 추가 심사 요건도 있다. 개발자 본인 계정의 테스트 성공을 모든 학생의 승인 완료로 안내하지 않는다.
